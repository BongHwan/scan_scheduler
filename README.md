# BookOasis 스캔 스케줄러

BookOasis 라이브러리의 새로고침 스케줄을 요일별·월별 달력으로 확인하고 관리하는 플러그인입니다.

## 주요 기능

- 일반, 성인, 오디오북, 비디오 카테고리의 라이브러리 스케줄을 한 화면에서 확인합니다.
- 요일별 시간표와 월별 달력 보기 사이를 전환할 수 있습니다.
- 라이브러리별 Cron 스케줄을 수정할 수 있습니다.
- BookOasis의 라이브러리 설정에서 `사용`이 꺼진 항목은 스케줄러에 표시하지 않습니다.
- 원격 라이브러리의 VFS 새로고침 설정과 Rclone RC 주소를 함께 확인할 수 있습니다.

## 설치

BookOasis 플러그인 관리 화면에서 다음 저장소를 사용합니다.

`https://github.com/BongHwan/scan_scheduler`

설치 후 BookOasis를 재시작하면 스캔 스케줄러 메뉴가 나타납니다.
